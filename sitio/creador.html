Quién hace Caja Libre

Soy Elias Oziel Sánchez Fernández, ingeniero en ciencias de la computación. Caja Libre nació de ver lo que cuesta abrir una tienda: juntar para la renta, el primer surtido, el refrigerador… y, al buscar un sistema para cobrar, toparse con mensualidades y equipos especiales que al empezar no se pueden pagar. Entonces se cobra con libreta y calculadora, y así se queda por años.

Lo que más se pierde no es dinero, es certeza: cuánto le toca hoy al de los refrescos, si alcanza para pagarles a los repartidores esta semana, qué día se puede cerrar temprano sin que pese. Por eso quise que la misma caja que cobra lleve las cuentas y, con las ventas de cada tienda, diga qué días son fuertes, qué pedirle a cada proveedor y qué productos solo ocupan espacio. La historia completa está en la página principal.

Lo hago solo y en mi tiempo. Es software libre (GPLv3): puedes usarlo en todas las cajas que quieras, copiarlo y regalarlo. El proyecto se sostiene con donaciones, y todo el código está publicado en GitHub junto con mis otros proyectos, varios de ellos trabajos de materias de la universidad (BUAP).

Caja Libre (Punto-Ventas)

Este punto de venta: gratis, de código abierto y pensado para la tienda de la esquina. Ventas con lector de códigos, inventario, corte de caja, estadísticas con las ventas reales, varias cajas con PostgreSQL y facturación CFDI 4.0. Hecho en Java 17 con JavaFX y Spring Boot; instaladores para Windows, Mac y Linux. El repositorio homebrew-tap publica el cask para instalarlo en Mac con un comando.

codigos-barras-mx

Catálogo libre de códigos de barras (EAN-13, UPC-A y EAN-8) de unos 25 000 productos que se venden en México, con nombre, marca, contenido, departamento e imagen. Se construye cada semana a partir de Open Food Facts y sus proyectos hermanos, más una lista curada a mano, y se publica como CSV, JSONL y una API estática de archivos JSON para consultar un código sin bajar todo.
